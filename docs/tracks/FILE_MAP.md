# TRACKS — file map

**Scope:** the catalog at `/tracks` (and `/tracks/new`, `/tracks/playlists`). 3D "The Jump" — a third-person Mirror's-Edge-inspired platformer. A low-poly runner stands on a rooftop in a procedural sunset city; click a banner = character vaults to that rooftop with a parabolic arc + animated limbs + body lean, song plays on landing. Camera trails the runner with smooth orbit + zoom + bass-bob. Mounts inside the same `index.html` shell as the galaxy.

**Build:** t28
**Updated:** 2026-05-12

## Architecture summary (t25 — The Jump)
- `tracks-jump.js` is loaded via a timestamped dynamic `<script type="module">` injection (`index.html` bottom). Module imports `three` + post FX from the importmap declared at the top of `index.html` (shared with `marathon-world.js` and the legacy tracks scenes).
- **Spatial model**: a procedural city is a 14×10 grid of buildings at `STEP=28u` pitch (~392u × 280u footprint). Heights are biased to peak at the city center (closer-to-center buildings are taller). Each cell gets one building with random jitter so the grid feels organic. Footprints 14-23u, heights 20-90u. ~140 buildings total + 60-building distant silhouette ring.
- **Track ↔ rooftop assignment**: every track gets ONE rooftop. Buildings are scored by `height - centerDistance × 0.12` so the tallest most-central rooftops go first. Tracks are ordered featured → new → archive and assigned in that priority order.
- **Banners**: per-track vertical red sign mounted on a back-edge of its rooftop, facing the city center. Sized + colored by tier (featured 4×12, new 3×9, archive 2.4×7). Baked canvas texture (192×640): red field, white hatched accent strips, side rails, title rotated -90° to read bottom→top, tier tag bottom-right. Halo plane behind (additive blending, DoubleSide).
- **Character**: low-poly runner built from primitives (capsule torso, sphere head, half-sphere hair, box hips/arms/legs/shoes). Arms and legs have pivot Groups so they swing around shoulders/hips during the jump. Materials use Lambert so the sun rig shades them like everything else.
- **Jump system**: `_jumpTo(roof)` computes start/end, distance `d`, duration `clamp(0.75 + d × 0.013, 0.9, 2.4)s`, apex `max(startY, endY) + min(18, 4 + d × 0.22)`. During the jump in `_updateCharacter(dt)`: horizontal uses ease-in-out-cubic, vertical uses quadratic Bezier through `(start.y, apexY, end.y)`. Limb swings: arms have `-arc * 1.3` baseline plus `flow * 0.20` cycle (arc = `sin(πt)`, flow = `sin(2πt)`); legs run the same with phase flipped. Body adds forward lean from `arc * 0.35`. Squash: 1.0 - 0.8 × (0.10 - t) for takeoff (`t < 0.10`), 1.0 - 1.4 × (t - 0.92) for landing (`t > 0.92`). Idle (when not jumping): gentle vertical bob from `sin(bodyBob)` + bass, mild Z-axis sway, subtle arm swings.
- **Camera (orbit chase)**: state is `{ az, el, dist }`. Drag = az/el adjust (el clamped [0.10, 1.30] rad). Wheel = dist multiplier (clamped [6, 60]). Each frame: build offset `(sin(az)cos(el)·dist, sin(el)·dist, cos(az)cos(el)·dist)`, target = character head, lerp `camPosNow` and `camTarget` toward those at `k = 0.10` (or `0.16` while jumping for tighter chase). `camera.lookAt(camTarget)` every frame.
- **God view** (O / Esc / OVERVIEW button): pulls camera to `(0, 360, charZ)` looking straight down. Click a banner in god view = exit + jump there. Click empty = exit.
- **Audio**: piggybacks `audio.__floorAnalyser` from `js/player.js` (same as galaxy + city + run). 3 smoothed bands (bass / mid / hi). Bass drives character idle bob amplitude + helicopter altitude. Mid drives active-banner halo opacity.
- **Background life**: 1 helicopter circling the city, 4 yellow construction cranes with hanging loads + counter-balances, 3 bird flocks (~24 birds total) on circular paths with vertical wobble, 60-building distant silhouette ring, ground plane at y=0 (matte dark concrete).
- **Filter chips + search**: same URL contract as the city + run — `/tracks/new` for NEW, `/tracks` otherwise. Search filters by title + tag substring. Hidden banners get `mesh.visible = false` + `halo.visible = false` + `haloMat.opacity = 0`.
- **Transport** (bottom pill): prev/play/next/seek/title/time. Prev/Next triggers `ctx.onPrev/onNext`; `onTrackChange` callback hops the character to the new track's rooftop (animates a jump without re-calling `onPlay` so we don't infinite-loop).

## Earlier architecture (t23 — The Run, retained for context)
- `tracks-run.js` is loaded via a timestamped dynamic `<script type="module">` injection so Vivaldi/Chrome don't serve stale modules during dev iteration. Module imports `three` + post FX from the importmap declared at the top of `index.html` (shared with `marathon-world.js` and the legacy `tracks-city.js`).
- **Spatial model**: a single 10u-wide concrete runway extending from `z=0` to `z = N × 14u + 200`, where N = number of tracks (~104 → ~1656u long). Camera sits 5u above the runway at first-person height, looking forward + slightly down. There is no orbit-around-anything; the entire navigation is "where am I along the path".
- **Navigation state**: `runT` (current, eased) and `targetT` (input destination), both in `[0, 1]` mapped onto the runway's z length. Inputs that drive `targetT`: mouse wheel (`deltaY × 0.00012`), W/S or arrow up/down (`±0.016` per keydown), vertical mouse drag (`dy × -0.0018`), 1-finger touch drag Y (`dy × -0.0024`). Arrow left/right are reserved for prev/next song (not camera motion). `runT` eases toward `targetT` each frame with a frame-rate-independent rate `k = 1 - 0.001^dt` (clamped to `min(1, k × 4.5)`).
- **Banners**: 3 tiers — featured (8×16×0.35, hangs above center at `y = RUNWAY_Y + 22` with a suspension wire), new (5×12×0.30, alternating L/R at `x = ±6.2`), archive (3×8×0.25, further out at `x = ±9.5`). Each has a baked canvas texture (256×768 portrait, red field, white hatched accent bars top/bottom, side rails, title rotated -90° to read bottom→top, tier tag at bottom-right). Each banner has a halo plane behind it (additive blending, opacity 0 unless active or focused).
- **Active vs focused**: `activeIdx` = banner closest to current `runT` (purely visual — slightly brightens that banner). `focusedIdx` = the track that's actually playing (`ctx.getCurrent()`), highlighted brighter with a bass-modulated halo. Click a banner = sets both, calls `ctx.onPlay(idx)`, glides `targetT` to that banner's z.
- **God view** (O or Esc): camera pulls 380u above the runway looking straight down, revealing all banners as a long red line through the city. Click anywhere = warp `targetT` to that z and return to first-person.
- **City**: 4 ranks of procedural buildings each side of the runway (white concrete, occasional glass strips in cool cyan-blue or warm orange, rare red/yellow accent stripes, rooftop vents and red blinker LEDs). 50 distant horizon silhouettes. 3 yellow construction cranes. 1 audio-reactive helicopter circling the scene with bass-driven altitude bob.
- **Sky**: `ShaderMaterial` on the inside of a 4500u sphere. Vertex gradient zenith → orange horizon, plus a pinned sun (dot-product power 90 for the hot core + power 8 for the bloom) and slow horizontal cloud bands.
- **Audio**: piggybacks the cached `audio.__floorAnalyser` from `js/player.js` (same as galaxy + city). 3 smoothed bands (bass/mid/hi) feed the camera bob, banner halo on active, and helicopter altitude.
- **Filter chips + search**: same URL contract as the city — `/tracks/new` for NEW, `/tracks` otherwise. Search filters by title + tag substring. Hidden banners' `mesh.visible` + `halo.visible` toggle off; they're skipped in active-banner detection.
- **Transport** (bottom pill): prev/play/next/seek/title/time. Prev/Next trigger `ctx.onPrev/onNext`; `onTrackChange` callback glides the camera to that track's banner (`targetT = (bannerT - 12) / totalLength`), so prev/next browses song-by-song without leaving the run.
